📱 О проекте
District App: Кейс полного цикла Android-разработки и AppSec

Локальный маркетплейс для соседей с фокусом на безопасность

Этот проект демонстрирует полный цикл Android-разработки с интеграцией AppSec-практик. Приложение создавалось не просто как рабочий продукт, а как живой кейс: от написания кода до аудита безопасности и внедрения защитных механизмов.

· Лента объявлений с пагинацией
· Детальный просмотр объявлений
· Добавление в избранное
· Профиль пользователя
· Регистрация / логин / обновление токенов

Технический стек

· Язык: Kotlin
· UI: Jetpack Compose + Material Design 3
· Архитектура: Clean Architecture (domain / data / presentation)
· Безопасность: AndroidX Security Crypto (EncryptedSharedPreferences)
· Сеть: OkHttp / Retrofit (с поддержкой HMAC)

🖥 Бэкенд

Приложение работает с собственным бэкендом, разработанным на FastAPI.
Бэкенд обеспечивает:

· JWT-аутентификацию (access + refresh token)
· HMAC-подпись запросов (защита от подделки)
· Nonce + timestamp (защита от replay-атак)
· Rate limiting
· Хеширование паролей (PBKDF2 + соль)
· PostgreSQL

🔬 Главная ценность проекта — Security Journey

Уникальность проекта — в его эволюции.
Он показывает путь от разработчика к специалисту по безопасности мобильных приложений.

Что было сделано:

· Проведён аудит безопасности по методологии OWASP MSTG
· Внедрены защитные механизмы на основе выводов аудита
· Задокументирован весь процесс: от поиска уязвимостей до их устранения
